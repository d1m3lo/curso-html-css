Para desativar o autocomplete, basta ir na tag <form> e dentro dela escrever autocomplete="off".

Ao usar a tag <label for=""> dentro do for, sempre colocar o id.

Label usado para relacionar objeto de formulário e sua etiqueta, demonstrando a relação de ambos.

O metódo padrão dos formulários é o "GET". Ao enviar dados usando "GET" o máximo de dados possiveis a serem enviados é de  3mil bites (3 mil letras).

HTTPS para proteção de dados.

O post suporta mais de 3mil bites.

input do type="password", não mostra a senha.

type "submit" usado para criar botões de enviar.

type "reset" usado para limpar os dados dos campos.

Estudar mais sobre RegEx ( regular expression).

 Botões de Radio usado para quando você quer selecionar somente uma opção, e os botões checkbox usados para mais de uma opção.

 Ao usar o envio de arquivos não se deve usar o metódo get e sim o metódo post.


 Ao se usar output para fazer contas em formulários, o resultado será transmitido somente visualmente na página, ao enviar o url não conterá a soma e sim os valores propostos.
